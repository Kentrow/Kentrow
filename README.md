# Hi, I'm Quentin

Network, automation & observability engineer based in France.

By day, I help teams see what their infrastructure is actually doing. On the side, I build the tools I wish I had: small, focused, open source, and properly documented.

I also write about homelab, networking, DevOps and self-hosting on [kentrow.fr](https://kentrow.fr), in French and English.
