## Projects

### Observability & network tooling

**[tapyr](https://github.com/kentrow/tapyr)** · [tapyr.eu](https://tapyr.eu)
&nbsp;![Go](https://img.shields.io/badge/Go-00ADD8?style=flat-square&logo=go&logoColor=white)
![version](https://img.shields.io/github/v/tag/kentrow/tapyr?sort=semver&style=flat-square&label=)<br>
Declarative API-to-metrics gateway for cloud-managed network gear (Aruba Central, Meraki, Teltonika...). Treats vendor rate limits as a budget, plans every call, exposes Prometheus and OTLP.

**[grafana-rackelevation-panel](https://github.com/kentrow/grafana-rackelevation-panel)**
&nbsp;![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![version](https://img.shields.io/github/v/tag/kentrow/grafana-rackelevation-panel?sort=semver&style=flat-square&label=)<br>
Draws your racks unit by unit from inventory data (NetBox, CSV, SQL, Prometheus...) and colours each device by state or any metric.

**[grafana-wificoverage-panel](https://github.com/kentrow/grafana-wificoverage-panel)**
&nbsp;![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![version](https://img.shields.io/github/v/tag/kentrow/grafana-wificoverage-panel?sort=semver&style=flat-square&label=)<br>
Predicted Wi-Fi coverage on floor plans, right inside Grafana.

## Open source involvement

- **[nl6](https://github.com/labmonkeys-space/nl6)** · co-maintainer. Open network load simulator running thousands of simulated devices on one host (SNMP, NetFlow, IPFIX, sFlow, Syslog, gNMI, NETCONF), part of [labmonkeys-space](https://github.com/labmonkeys-space).
- **[oxynote](https://github.com/oxynote/oxynote)** · contributor. Open source technical wiki connected to the systems it describes.

## What I care about

- Observability that answers questions, not just dashboards that collect data
- Infrastructure described as code rather than tribal knowledge
- Tools that do one thing well and are honest about their limits
- Releases you can rely on: semantic versioning, changelogs, no surprises
